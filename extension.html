ไฟล์ถูกบันทึกไว้ที่ไหน?Where are files saved?

ในโฟลเดอร์ Downloads เริ่มต้นของ Chrome ภายใต้ EmailToFolder/<โฟลเดอร์ตามกฎ>/... เช่น Downloads/EmailToFolder/Finance/2026/10/ — หากต้องการบันทึกลง NAS หรือ Network Drive ให้เปลี่ยนตำแหน่งดาวน์โหลดของ Chrome (Settings → Downloads → Location) ไปยังไดรฟ์นั้นIn Chrome's default Downloads folder under EmailToFolder/<rule folder>/..., e.g. Downloads/EmailToFolder/Finance/2026/10/. To save to a NAS or network drive, change Chrome's download location (Settings → Downloads → Location) to that drive.

ทำไมบันทึกเป็น .eml ไม่ใช่ .msg?Why .eml and not .msg?

Gmail API และ Microsoft Graph ส่งอีเมลต้นฉบับมาในรูปแบบ MIME มาตรฐาน (.eml) ซึ่งเปิดได้ทั้ง Outlook, Thunderbird และ Apple Mail ครบทั้งเนื้อหาและไฟล์แนบ ส่วนไฟล์ .msg แท้ต้องอาศัย Outlook Classic บน Windows — ใช้ โปรแกรม Desktop หากต้องการ .msgGmail API and Microsoft Graph deliver the original message as standard MIME (.eml), which opens in Outlook, Thunderbird and Apple Mail with full body and attachments. Native .msg requires Outlook Classic on Windows — use the desktop app if you need .msg.

ส่วนขยายส่งอีเมลของฉันไปเซิร์ฟเวอร์อื่นหรือไม่?Does it send my emails to a server?

ไม่ ทุกอย่างประมวลผลภายในเบราว์เซอร์ของคุณ โดยคุยกับ Google / Microsoft โดยตรงด้วย OAuth Client ID ของคุณเอง ไม่มีเซิร์ฟเวอร์กลางของเรา ขอสิทธิ์อ่านอย่างเดียว (read-only) — ส่วนขยายไม่สามารถลบ ย้าย หรือส่งอีเมลได้No. Everything runs in your browser, talking directly to Google / Microsoft with your own OAuth Client ID. There is no server of ours in between, and only read-only scopes are requested — the extension cannot delete, move or send mail.

โควตาฟรี 100 ฉบับ/เดือน ทำงานอย่างไร?How does the free 100 emails/month quota work?

ทุกครั้งที่บันทึกอีเมลสำเร็จ 1 ฉบับจะนับ 1 โควตา (ไฟล์แนบไม่นับเพิ่ม) และรีเซ็ตเป็น 0/100 อัตโนมัติทุกวันที่ 1 ของเดือน เหมือนโปรแกรม Desktop หากต้องการแบบไม่จำกัด ติดต่อทีมงานEach successfully saved email counts as one (attachments don't count extra), and the counter resets to 0/100 on the 1st of every month — same as the desktop app. Need unlimited? Contact us.

ทำไมต้องเปิด Developer mode?Why do I need Developer mode?

ขณะนี้ส่วนขยายแจกจ่ายเป็นไฟล์ .zip โดยตรง (ยังไม่อยู่บน Chrome Web Store) Chrome จึงต้องใช้ Developer mode เพื่อ Load unpacked — โค้ดทั้งหมดเปิดให้ตรวจสอบได้ในโฟลเดอร์ที่แตกไฟล์The extension is currently distributed as a direct .zip (not yet on the Chrome Web Store), so Chrome requires Developer mode for Load unpacked. All code is readable in the unzipped folder.
