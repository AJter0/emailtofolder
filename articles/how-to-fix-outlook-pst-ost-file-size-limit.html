วิธีแก้ปัญหาไฟล์ Outlook PST / OST เต็มขนาด 50GB: เทคนิคบีบอัดไฟล์และแยกไฟล์แนบไม่ให้เครื่องค้าง How to Fix Outlook PST / OST 50GB File Size Limit & Prevent Freezing

หนึ่งในปัญหาคลาสสิกที่ฝ่าย IT ในองค์กรต้องปวดหัวมากที่สุด คือเมื่อผู้บริหารหรือพนักงานเปิด Outlook แล้วพบข้อความเตือน "The Outlook Data File (.pst/.ost) has reached the maximum size" ส่งผลให้ไม่สามารถรับ-ส่งอีเมลใหม่ได้ โปรแกรมเปิดไม่ขึ้น หรือค้าง (Not Responding) ตลอดเวลา

1. ทำความรู้จักข้อจำกัด 50GB ของไฟล์ Outlook PST และ OST

ตั้งแต่ Microsoft Outlook 2010 จนถึง Outlook 2021 และ Microsoft 365 ค่า Default ของขนาดไฟล์ข้อมูลในเครื่อง:

  • ไฟล์ `.pst` (Personal Storage Table): ใช้สำหรับจัดเก็บอีเมล Archive หรือบัญชีแบบ POP3 ขนาดสูงสุดจำกัดไว้ที่ 50 GB
  • ไฟล์ `.ost` (Offline Storage Table): ใช้แคชอีเมลสำหรับบัญชี Microsoft 365, Exchange และ IMAP บนเครื่อง ขนาดสูงสุดจำกัดไว้ที่ 50 GB เช่นกัน

2. สัญญาณเตือนเมื่อไฟล์ Outlook ใกล้เต็มลิมิต

ก่อนที่ Outlook จะพังหรือเปิดไม่ได้ มักมีอาการเตือนล่วงหน้าดังนี้:

  • โปรแกรมใช้เวลาเปิดนานผิดปกติ (บางครั้งเกิน 2-5 นาที)
  • เวลาค้นหาอีเมลในช่อง Search จะช้ามาก หรือผลการค้นหาไม่ครบ
  • เวลากดลบอีเมลแล้วขึ้นข้อความว่าพื้นที่ไม่พอให้ลบ
  • เกิดข้อผิดพลาดในการ Send/Receive อยู่บ่อยครั้ง
⚠️ อันตรายจากการปล่อยให้ไฟล์เกิน 50GB: หากไฟล์ `.pst` เสียหายจากขนาดที่เกินขีดจำกัด โอกาสที่เครื่องมือซ่อมแซมอย่าง ScanPST.exe จะกู้คืนข้อมูลได้มีน้อยมาก และอาจทำให้ประวัติการติดต่อลูกค้าย้อนหลังหลายปีสูญหายถาวร

3. วิธีแก้ปัญหาชั่วคราว: ฟังก์ชัน Compact Now และการลบเมลเก่า

เมื่อคุณลบอีเมลออกจาก Outlook ขนาดไฟล์ `.pst` จะยังไม่ลดลงทันที เพราะ Outlook ยังเก็บพื้นที่ว่าง (White Space) ไว้ คุณต้องทำการบีบอัดไฟล์ด้วยตนเอง:

  1. ไปที่เมนู File > Account Settings > Account Settings...
  2. เลือกแท็บ Data Files แล้วดับเบิ้ลคลิกไฟล์ที่ต้องการ
  3. คลิกปุ่ม Settings... จากนั้นกด Compact Now

ข้อสังเกต: ขั้นตอนนี้อาจใช้เวลาหลายชั่วโมงขึ้นอยู่กับขนาดไฟล์ และมักช่วยลดขนาดได้เพียงชั่วคราวเท่านั้น

4. ทำไมการขยาย Registry Limit ไม่ใช่วิธีแก้ปัญหาที่ยั่งยืน

แอดมินหลายคนเลือกวิธีแก้ไข Windows Registry (`MaxLargeFileSize` และ `WarnLargeFileSize`) เพื่อขยายเพดานไฟล์เป็น 100GB หรือมากกว่า แต่ผลข้างเคียงคือ:

  • ฮาร์ดดิสก์ของเครื่องทำงานหนัก (Disk Usage 100%)
  • แรมถูกกินไปกับการโหลดดัชนี (Search Indexer) จนเครื่องทำงานช้าทั้งระบบ
  • เสี่ยงต่อการที่ไฟล์ฐานข้อมูลเสียหาย (Database Corruption) สูงขึ้นอย่างมาก

5. วิธีแก้ปัญหาถาวร: สกัดไฟล์แนบและอีเมลลงโฟลเดอร์ภายนอกอัตโนมัติ

กว่า 80-90% ของขนาดไฟล์ Outlook คือ "ไฟล์แนบ (Attachments)" เช่น แคตตาล็อกสินค้า, เอกสาร PDF, สเปรดชีต Excel และภาพถ่ายความละเอียดสูง

วิธีแก้ปัญหาที่ดีที่สุดและองค์กรชั้นนำเลือกใช้ คือการติดตั้งซอฟต์แวร์ Email to Folder เพื่อ:

  • ดึงอีเมลและไฟล์แนบออกไปเก็บในโฟลเดอร์ภายนอกอัตโนมัติ: ทันทีที่มีอีเมลใหม่เข้ามา ระบบจะสกัดไฟล์ PDF หรือ Excel ไปเก็บไว้ในโฟลเดอร์บน Network Drive หรือ NAS ทันที
  • บันทึกเป็นไฟล์ `.msg` แท้: สามารถดับเบิ้ลคลิกเปิดดูได้ทุกเมื่อเหมือนอยู่ใน Outlook โดยไม่ต้องเปลืองพื้นที่ไฟล์ `.pst/.ost` ในเครื่อง
  • จัดโครงสร้างตามปีและเดือน (`YYYY/MM`): เอกสารปีเก่าจะถูกแยกเป็นโฟลเดอร์อย่างเป็นระเบียบ ค้นหาง่าย และแชร์ให้ทุกคนในแผนกใช้งานร่วมกันได้
